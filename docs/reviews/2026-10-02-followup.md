# Output, notification and console review — 2026-10-02

Base: `a28c34d4c60de14f1a6788eda95889698161d4c9`, after the
[first review](2026-10-02.md). Runtime dependency remains
`@anthropic-ai/sandbox-runtime` **0.0.78**.

This pass follows credential output across chunk boundaries and process exit,
notification configuration and failure handling, console link storage and CLI
option parsing. It corrects reproduced Seisin defects without changing the
runtime pin or treating output redaction as a containment boundary.

## Findings corrected

| Area | Before | After and regression evidence |
| --- | --- | --- |
| Shared credential prefixes | A short value could be replaced before a longer value finished arriving, leaving the longer value's suffix visible. | Retains raw input until the longest possible match is decidable. Tests every byte split of ASCII and UTF-8 examples. |
| Redaction markers | Replacement text could itself match another credential, including in a later chunk. | Only original input is searched; markers are output once. |
| Notification URL file | Lexical comparison missed path aliases, symlinks, enclosing directory reads and builtin file references. An absolute protected directory inside the repo was rejected. | Compares canonical paths and the builtin resolver's fragment rules. Rejects URL delivery to a role or a URL file outside the protected directories. |
| Notification errors | A native fetch exception could embed the whole credential-bearing URL in stderr. | Uses known failure categories and never copies the exception message. The regression uses an invalid URL that fails before any network request. |
| Notification completion | A completed request left a referenced settlement timer keeping its caller alive until the cap. | Clears that timer after the race settles. A subprocess must finish naturally before the old 3.5-second cap. |
| Console link storage | Updating an existing file retained its permissions and followed its symlink. | Writes a private exclusive temporary file and renames it over the record. Tests mode `0600`, intact symlink targets and complete readable records. |
| Console liveness | Any signal-check error meant the writer was gone. | Only a missing process is gone; an `EPERM` signal check still reports it alive. |
| CLI help | The help scanner did not know `--agent` took a value. It missed a following help flag or treated the value itself as help. | Gets value-taking flags from the command's existing definition and preserves the child command's own arguments. |
| Output completion | Ending the redactors on runtime exit discarded output from pipes that had not reached EOF. | Lets the pipes end the transforms, retaining the existing two-second guard and exit status. A fake runtime tests stdio ordering, redacted late stdout and late stderr; it makes no confinement claim. |
| CI enforcement gate | The shell guard recognised TAP's `# skipped`, but missed the spec reporter's `ℹ skipped` summary. | Recognises both formats. The regression executes the workflow's actual shell commands against passing and skipped native Node fixtures in both reporters. |

On merge (2026-10-10) the CI gate row was superseded by a stricter one: the workflow pins
the TAP reporter and requires the whole sandbox suite to run, so the spec-reporter summary
never reaches the gate. The regression was rewritten to run that step.

The notification check covers declared file reads and the builtin `file://`
resolver. Custom provider programs remain trusted author commands; this change
does not try to infer their filesystem access. Canonical checks describe the
filesystem at validation time and do not establish protection against every
subsequent filesystem change.
